# Portfolio Studio

个人作品展示与交互杂志框架，支持摄影、项目档案、视频、音频、游戏评价、电影手记和文字随笔。界面采用灰绿底色、留白、毛玻璃和轻量动态效果，使用原生 JavaScript 与 Node.js。

## 开始使用

需要 Node.js 24.5 或更新版本，以及 npm。

```sh
npm ci
npm run dev
```

打开 `http://127.0.0.1:4175/` 预览网站，打开 `http://127.0.0.1:4175/manage/` 编辑内容。首次安装会从通用示例初始化本地数据。也可以运行 `npm run setup`。

默认作品列表为空，可以在本地管理台添加自己的内容。

## 功能

- 摄影支持随机选展、横竖图拼贴、独立作品集、图片放大和触控查看。
- 视频支持本地文件与 Bilibili 嵌入，声音展示支持播放与动态波形。
- 项目档案支持翻页展示和详情阅读。
- 游戏简评在弹窗中阅读，详评使用固定比例的杂志画布。电脑显示双页，手机显示单页，支持完整跨页查看。
- 杂志工作台支持文本与图片拖拽、缩放、图层、字体、纸张纹理、可还原图像效果及多种图文组件。
- 电影手记与随笔支持图文编排和交互预设。
- 编辑自动保存草稿，支持单条与批量发布、历史恢复，以及文件夹和标签素材库。
- 封面检索支持 Steam、Bangumi、豆瓣和 IMDb。游戏素材检索支持来源记录与手动选图路径。

## 内容与版本控制

仓库提供 `public/*.example.json` 通用配置。安装后生成的 `site.json`、`content.json`、`journal.json`、`writing.json`，以及上传素材、草稿、历史记录和构建输出均已配置 Git 忽略规则。

在管理台填写自己的介绍、联系方式和作品。需要修改框架默认内容时，编辑对应的 `.example.json` 和页面中的默认文案。`site-config.js` 定义可编辑字段及其选择器。

本地管理服务绑定 `127.0.0.1`，写入操作验证本机连接、Host、Origin 和请求令牌。

## 测试和静态构建

```sh
npm test
npm run build
node server.mjs --public
```

构建输出位于 `dist/`。只读预览地址为 `http://127.0.0.1:4176/`。

部署时将 `dist/` 的内容放入静态服务器目录。`deploy/nginx.conf` 提供 Nginx 示例，其中路径和端口可按自己的环境修改。管理台、写入接口、草稿与未发布素材会在构建中排除。

## 目录

```text
public/          页面、渲染器、视觉样式与通用配置示例
local/           本地管理 API、素材库与编辑器界面
scripts/         初始化、摄影预览和静态构建
tests/           数据模型、编辑流程、安全边界与渲染测试
deploy/          静态部署配置示例
```
